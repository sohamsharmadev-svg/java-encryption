How it works
STEP 01

Key Generation

All 95 printable ASCII characters (space to ~) are shuffled into a random mapping key.

STEP 02

Substitution

Each character in your message is replaced by its counterpart in the shuffled key.

STEP 03

Decryption

The reverse lookup maps each encrypted character back to the original using the same key.

STEP 04

Custom Keys

Share your key with someone — they can decrypt your message using the same key.
